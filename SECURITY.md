# Security Policy

## Supported Versions

Security fixes are released for the latest published version only.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.3   | :white_check_mark: |
| < 0.0.3 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Report it privately through
   [GitHub security advisories](https://github.com/nisargratani/elegant_loading_overlay/security/advisories/new).
3. Include steps to reproduce the issue and the affected version.
4. Allow reasonable time for a fix before public disclosure.
